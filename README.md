# `zigzoom`

 A renderer written in Zig 0.17 using only ray tracing, with no dependencies beyond the standard library. 

 It starts from the features of [*Ray Tracing in One Weekend*](https://raytracing.github.io/books/RayTracingInOneWeekend.html) and is built around swappable backends, beginning with a CPU reference renderer.
